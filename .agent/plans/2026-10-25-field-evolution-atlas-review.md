# 领域演化图 ExecPlan 审查

日期：2026-10-25。对象：`2026-10-25-field-evolution-atlas.md`。依据：当前分支源码、接口定义、现有测试和用户要求。审查与实施分开进行。

结论：方案可以在现有架构上实现，无需新存储或生产依赖。实施前需把范围选择、论文投影、主线算法和预算语义写成明确契约。以下修订纳入计划后可实施。

## 实质性发现与处理

1. **领域全景不能沿用普通搜索的 50 组上限。** `searchGraph` 内部的 `MAX_SEARCH_RESULT_LIMIT=50` 会让“全景”仍由检索预览决定。改为对已有论文标题、摘要、关键词及关联方法/问题的文本做确定性的完整扫描，query 使用全部非停用词匹配；领域标签精确忽略大小写匹配。明确种子使用精确 ID。返回选中与遗漏数量，并说明这是库内词法/标签范围，不是领域完整性证明。

2. **论文关联不等于方法首创论文。** 方法可关联多篇论文，不能把方法边在所有关联论文之间做笛卡尔积。论文投影优先使用关系记录的 sourcePaper/targetPaper；缺失时只使用唯一可解析的端点论文。多义归属保留方法证据并计入诊断，不生成猜测连线。图内同论文方法边不生成论文自环。

3. **主线和转折需要可解释规则。** 主线定义为每个无环相连家族的最长已验证路径，等长以稳定 ID 顺序选择，不使用启发式学术影响力评分。分叉/合流按不同后继/前驱计数，替换来自论文报告关系，跨域适配单独标记。循环家族保留关系、报告循环、停止为该家族选主线，不任意删除冲突关系来构造 DAG。年份分组只称年度分布。

4. **预算和时间范围必须避免隐藏数据损失。** `maxNodes` 分别限制方法视图和论文视图，`maxEdges` 分别限制去重后的方法关系与论文投影；报告每层实际与可用数量。年份范围是显示范围的硬筛选，未知年份单列；跨域谱系上下文必须标为 boundary，不能冒充核心领域论文。关系端点预算外时不显示悬空连线，记录其省略原因。

5. **界面完成不能仅靠 HTML 字符串测试。** 保留真实浏览器验收，增加快速语料切换/旧请求响应、零结果、图内点击证据与下载内容核验。校验的是使用过程，而不只是函数返回字符串。
