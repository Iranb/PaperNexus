# 领域谱系方案审核

2026-10-26。审核目标是用户能在原生 Web 打开两套真实研究，且数量不再替代覆盖判断。

通过前需要明确的事项已纳入实施约束：

1. 保存研究必须只保存范围与审核记录，读取地图时使用当前权威图，不能把生成 JSON 当第二图数据库。
2. 研究论文记录使用 `methodIds` 数组，允许一篇多个方法或变体；论文角色和分支成员关系只保留一份来源。方法边必须已有原文核验状态。
3. 批次 `completed` 保持兼容，但必须带 `coverageAssessment.status=not_assessed`；研究的覆盖复核单独保存。缺少分支检索记录、仍未处理的重要遗漏时，不能声称已复核覆盖充分。
4. 页面必须从服务端列举研究并支持 URL 恢复，避免“恢复最近一轮”覆盖另一主题。分支选择和显示预算都应可见，不能把显示数量当纳入数量。
5. 更新 canonical skill 后使用安装预览和备份定向同步，防止仓库有而本机不可发现。
6. 真实文献工作保留全部检索候选和纳入排除理由；多个检索提供者与引文扩展按主要分支推进。预算用来控制一次工作，不作为总体完成条件。继承声明采用原文和出处核验，不能把模型产出的关系总数当核验数量。
7. 用户本轮已授权部署同一服务、更新原库和使用此前选定的 DeepSeek Flash。执行前保留快照，先查现有任务；不启动 GPU 或其它研究实验。

方案可实施。按 ExecPlan rubric 审核为 20/20；用户可见结果、当前状态、验收和恢复均具备具体依据，远端写入和付费调用的授权、预览、记录和回滚路径完整。完成状态仍以实际结果验收为准。
