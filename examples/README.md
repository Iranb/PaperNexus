# PaperNexus Examples

This directory contains small paper-like source documents that can be used as input material for local smoke tests and documentation examples.

They are not API tutorials and they are not benchmark ground truth. For operating the system, start with:

- [Get Started](../docs/get-started/index.md)
- [Pipeline Overview](../docs/pipeline/index.md)
- [Literature Discovery](../docs/literature-discovery/index.md)
- [Interfaces Overview](../docs/interfaces/index.md)
- [Generated CLI Reference](../docs/reference/generated/cli.md)

Example build:

```bash
papernexus analyze ./examples --name sample-papers
```
