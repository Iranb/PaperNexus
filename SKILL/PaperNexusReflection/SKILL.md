# PaperNexus Reflection

Read [the shared remote contract](../PaperNexus/references/remote-contract.md). Use this advanced stage when actual outcomes or experiment-reflection records exist; ordinary literature analysis does not require it.

Use advertised research_briefing/reflection_chain for Innovation → Experiment → Outcome → Reflection, paper_enhancement for one source's overlay, and evidence_chain for grounding. If these tools are not advertised, select a supported advanced profile and reconnect rather than inventing a route.

An empty chain may mean missing overlay data, quarantined evidence or missing anchors. It does not mean experiments succeeded, risks vanished or a scientific gap exists. Read the original paper/outcome authority before summarizing.

Return intervention, protocol, observed result, supporting evidence, failure/alternative explanation and next discriminating check. Separate paper-reported results, reproduced results and matched reproduction; only verified protocol alignment permits a matched comparison.

New uploads and graph refresh belong to [maintenance](../PaperNexusMaintenance/SKILL.md). Reuse authorization in scope; preserve original experiment-state authority. Local mirrors and reviewer commentary cannot promote claims or approve training.

Existing scripts in this directory remain compatible forwarding entrypoints into `SKILL/PaperNexus/scripts`.
