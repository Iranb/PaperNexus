# Reference Hub

This section is the entry point for low-level, high-authority documentation.

## What Is Generated

The following pages are rebuilt from code and configuration:

- CLI reference
- MCP tool reference
- configuration reference
- graph schema reference
- HTTP serve route reference
- module map
- scripts and SKILL wrapper catalog

## What Is Narrative

The surrounding pages under the main docs hubs are hand-maintained narrative documentation. Those pages explain why the system is built the way it is and how major subsystems interact. The generated pages explain what the code currently exposes.

## Recommended Usage

- Start with the narrative hubs when you are new to the system.
- Jump straight into generated pages when you already know the subsystem and need exact command, tool, or schema details.
